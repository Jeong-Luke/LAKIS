LAKIS CMD 대체 설치

LAKIS_Setup.exe가 Windows Defender 오탐으로 차단될 때 사용하는 Fresh 설치 전용 경로입니다.

1. 이 ZIP의 파일을 모두 같은 폴더에 압축 해제합니다.
2. LAKIS_CMD_Install.cmd를 더블클릭합니다.
3. 다운로드와 SHA-256 검증이 끝날 때까지 CMD 창을 닫지 않습니다.
4. 설치가 끝나면 LAKIS가 자동 실행됩니다.

기본 설치 위치:
%LOCALAPPDATA%\Programs\LAKIS

안전 계약:
- 관리자 권한을 요구하지 않습니다.
- PowerShell을 사용하지 않습니다.
- Windows Defender를 끄거나 예외를 만들지 않습니다.
- GitHub와 공식 모델 배포처의 고정 URL만 사용합니다.
- 다운로드한 모든 파일의 SHA-256을 확인합니다.
- WebView2 Runtime이 없으면 Microsoft 공식 설치 파일을 SHA-256 확인 후 설치합니다.
- 기존 파일이 있는 설치 폴더에는 설치하지 않습니다.
- 실패한 staging을 실제 설치 폴더로 승격하지 않습니다.
- 실패 시 화면에 표시되는 임시 폴더는 오류 확인을 위해 남겨 둡니다. 설치 성공 후에도 다운로드 캐시와 압축 해제 자료가 남을 수 있습니다.

필요 환경:
- Windows 10 1803 이상 또는 Windows 11
- 충분한 저장 공간
- 안정적인 인터넷 연결

GUI와 CMD 설치기는 동일한 고정 8.0 실행 환경을 내려받아 검증·설치합니다. 처음 받는 ComfyUI portable은 설치 도구를 실행할 Python 준비용이며, 그 구버전 실행 환경을 LAKIS 설치 위치에 복사하지 않습니다. 모델은 프로그램 패키지에 포함하지 않고 공식 배포처에서 별도로 내려받아 SHA-256을 확인합니다. 기존 파일이 있는 폴더의 업데이트·복구는 CMD 신규 설치가 아니라 LAKIS 업데이터 또는 GUI 설치기의 복구 기능을 사용하세요.
