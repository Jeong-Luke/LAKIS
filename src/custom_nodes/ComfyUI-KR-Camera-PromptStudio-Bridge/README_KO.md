# KR Camera → Anima Prompt Studio 실시간 브리지

`KR_CameraControl`이 화면에 표시하는 최종 카메라 프롬프트를
`EasyUseAnimaPromptStudioAdvanced`의 전용 **구도 설정** 필드에 실시간으로 넣습니다.

## 설치

1. 이 폴더를 그대로 `ComfyUI/custom_nodes/` 안에 넣습니다.
2. 최종 경로가 아래처럼 되면 됩니다.

   `ComfyUI/custom_nodes/ComfyUI-KR-Camera-PromptStudio-Bridge/__init__.py`

3. ComfyUI를 완전히 재시작합니다.
4. 브라우저에서 `Ctrl+F5`로 새로고침합니다.
5. 동봉된 `KR_Camera_Anima_실시간연동_ONOFF.json` 워크플로를 엽니다.

별도 Python 패키지 설치는 필요하지 않습니다.

## 동작

- KR 카메라 노드에 `Prompt Studio 구도 자동 입력` 스위치가 나타납니다.
- 긍정 프롬프트의 추가 버튼 줄에 `+ 구도` 버튼이 나타납니다.
- 구도 필드가 있으면 `+ 구도`가 비활성화되고, `X`로 삭제하면 다시 활성화됩니다.
- `+ 구도`로 다시 만든 필드는 긍정 프롬프트의 맨 뒤에 추가됩니다.
- 제목 번호는 실제 위치에 맞춰 `3. 구도 설정`, `5. 구도 설정`처럼 자동으로 바뀝니다.
- **ON**: 카메라를 움직이거나 설정·프리셋을 바꾸면 구도 필드가 즉시 갱신됩니다.
- **OFF**: 구도 필드를 즉시 비우며 이후 카메라 조작을 반영하지 않습니다.
- 카메라는 화면 번호가 아니라 전용 필드 ID를 추적하므로 위치가 바뀌어도 해당 구도 필드에만 연동됩니다.
- Prompt Studio Advanced의 모든 긍정·부정 프롬프트 칸을 안정적인 수동 높이 모드로 관리합니다.
- 기존 칸 높이는 유지하고 비정상적으로 큰 값은 360px로 제한하며, 긴 내용은 칸 내부에서 스크롤됩니다.
- 카메라 값을 연속으로 변경해도 구도 필드 높이는 64px로 유지됩니다.
- 동봉 워크플로에서는 기존 3번의 캐릭터 태그가 새 전용 필드 때문에 **4번으로 이동**합니다.
- 기존 태그 문자열은 삭제하거나 덮어쓰지 않습니다.
- 노드 연결선을 추가하지 않으며, Prompt Studio의 실제 저장 데이터와 화면 textarea를 함께 갱신합니다.

## 참고

- 동봉 워크플로의 KR 카메라와 Prompt Studio Advanced는 대상 노드 ID 및 전용 필드 ID가 미리 지정되어 있습니다.
- 다른 워크플로에서도 `+ 구도`를 누르면 카메라 전용 필드가 자동으로 만들어집니다.
- EasyUse Anima나 KR Camera Control을 업데이트한 뒤 표시가 사라지면 먼저 ComfyUI 재시작 후 `Ctrl+F5`를 해주세요.
